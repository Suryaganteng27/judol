# 🎱 8 Ball Pool 3D (Web-Based Game)

Game Biliar 3D berbasis web yang dibuat dengan **HTML5**, **CSS3**, dan **Three.js**. Game ini memiliki fitur bermain lawan komputer (AI) maupun 2 pemain secara lokal di satu perangkat.

## 🎮 Cara Bermain

1. **Buka Game** di browser web Anda (atau via GitHub Pages).
2. **Pilih Mode Permainan** pada menu utama:
   - **2 Player (Lokal):** Main bergantian bersama teman di satu layar/HP/PC.
   - **Lawan Computer (Bot):** Bertanding melawan AI secara otomatis.
3. **Membidik & Memukul:**
   - Arahkan mouse untuk menyesuaikan posisi sodokan.
   - **Klik Kiri Mouse / Sentuh Layar** untuk memukul bola putih (*Cue Ball*).
4. **Aturan Waktu & Level:**
   - Anda memiliki **30 detik** setiap gilirannya. Jika waktu habis, giliran akan otomatis berganti ke pemain lain/komputer.
   - Setiap kali bola masuk, level permainan akan naik.

## ✨ Fitur Utama
- **Visual 3D & Animasi:** Menggunakan engine Three.js dengan tata cahaya dan bayangan realistis.
- **Efek Suara:** Dilengkapi dengan Audio Synthesizer internal tanpa memerlukan file audio eksternal.
- **Fitur Waktu & Level:** Dilengkapi *countdown timer* interaktif dan pelacak level.
- **Sistem Notifikasi UI:** Menampilkan giliran pemain dan pesan status di layar.
